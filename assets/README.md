# 圖表資產

目前技術圖直接寫在各章的 Mermaid 區塊，附上假設與文字解釋，方便 GitHub 與 HackMD 編修。未重製課程整頁或原文書圖片。

所有公開圖片統一放在本目錄。Markdown 圖片使用 `https://raw.githubusercontent.com/johnson931128/Distributed-System/main/assets/檔名` 完整 URL，不使用相對圖片路徑。先提交到 GitHub，再驗證外部顯示；只有本機 commit 不算完成。SVG 顯示異常時提供 PNG 備援。

每張圖須記錄來源、作者、授權與必要署名；自製圖註明自製及技術依據。關鍵說明保留文字版本。
